# Contributing to ColorMerge

Thank you for your interest in contributing to ColorMerge! This document provides guidelines for contributing to the project.

## Development Setup

1. Fork the repository
2. Clone your fork locally
3. Install dependencies: `npm install`
4. Set up environment variables (see `.env.example`)
5. Start development server: `npm run dev`

## Code Style

- Use TypeScript for all new code
- Follow existing code formatting
- Add appropriate comments for complex logic
- Ensure all TypeScript errors are resolved

## Testing

- Test your changes thoroughly in different browsers
- Verify mobile responsiveness
- Check that audio and haptic feedback work correctly
- Ensure no performance regressions

## Pull Request Process

1. Create a feature branch from `main`
2. Make your changes
3. Test thoroughly
4. Update documentation if needed
5. Submit a pull request with a clear description

## Security Guidelines

- Never commit API keys or sensitive data
- Use environment variables for configuration
- Follow secure coding practices
- Report security issues privately

## Game Design Principles

- Maintain the core color mixing mechanics
- Ensure accessibility across devices
- Keep the user experience smooth and intuitive
- Preserve the progressive difficulty system

## Questions?

Open an issue for questions or suggestions!
