🧩 GAME MODES TO INCLUDE:
	1.	Classic Mode (original ColorMerge)
	•	Keep as-is for early levels in Arcade Mode and standalone play.
	2.	Golf Ball Dimples
	•	A 3D rotatable sphere with colored dimples.
	•	Player taps each dimple and adds colors to blend it into the background.
	•	When matched, the dimple disappears.
	•	Variables: dimple count, blend difficulty, background complexity, rotation speed.
	3.	Strings / Bands
	•	Colored bands or lines overlay a multicolor background.
	•	Bands vary in number, width, curvature, orientation, and overlap.
	•	Player taps a band, adds colors, and matches it to make it disappear.
	4.	Concentric Circles
	•	Multiple nested circles where each layer builds upon the color of the previous.
	•	The goal is to match each ring to its intended blend, moving from inside out.
	•	Score based on speed and accuracy.
	5.	Flash Background
	•	The background briefly flashes on screen, then disappears.
	•	Player must recreate the background by blending colors from memory.
	•	Difficulty scales by increasing color complexity and decreasing flash time.
	6.	Tetris Falling Shapes
	•	Shapes fall from the top with partially blended colors.
	•	Player must tap and complete the blend before the shape hits the bottom.
	•	Shapes vary in form (circle, triangle, square, etc.).
	•	Background changes per round. Speed and complexity increase with difficulty.
	7.	Chaotic Bounce
	•	Blank or partially blended shapes bounce around the screen.
	•	Player must tap and match the background color before the screen becomes overcrowded.
	•	Difficulty increases with spawn rate, speed, and background color complexity.
	8.	Zen Fade
	•	The background fades slowly from one blended color mix to another.
	•	Player must match the current fade before the transition completes.
	•	Precision and timing become more challenging as the game progresses.

🎮 ARCADE MODE STRUCTURE:

Arcade Mode is an infinite campaign that cycles through the 8 total game modes. Each level pulls from one of the game types and increases in difficulty using a procedural system.

Game mode selection rotates every level using:

const gameModes = ["Classic", "GolfBall", "Strings", "Concentric", "FlashBG", "Tetris", "Chaotic", "ZenFade"];
const currentGame = gameModes[levelNumber % gameModes.length];

Difficulty increases over time using a Global Difficulty Index (GDI):

const GDI = levelNumber * 1.15;

Each level generates a settings object for the chosen game using GDI to scale:

{
  "level": 42,
  "game_mode": "GolfBall",
  "GDI": 48.3,
  "settings": {
    "dimples": 72,
    "background_colors": 5,
    "blend_variance": 0.2,
    "rotation_speed": 1.8
  }
}

Each mode’s internal difficulty will be adjusted using GDI:
	•	Increase number of elements (dimples, bands, shapes, etc.)
	•	Increase background complexity
	•	Increase spawn/fall/fade speed
	•	Tighten blend accuracy
	•	Add visual movement or layout complexity
